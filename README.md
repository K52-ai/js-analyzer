JS Analyzer
Extract endpoints, API keys, tokens, emails, and passwords from JavaScript files.
Author: K52-ai
Features
🔍 Extracts all JS files from a target page
🔑 Detects API keys (AWS, Google, Stripe, GitHub, Slack)
🎫 Detects JWT tokens
📧 Extracts emails
🌐 Finds internal hosts
🔒 Finds passwords in code
🎨 Rainbow banner in terminal
💾 Saves results to results.txt
Requirements
Python 3.9+
requests, beautifulsoup4, colorama
Installation
git clone https://github.com/K52-ai/js-analyzer.git
cd js-analyzer
pip install -r requirements.txt
